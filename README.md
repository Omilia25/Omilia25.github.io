## 🚀 How to Deploy to GitHub Pages (`Omilia25.github.io`)

Because `index.html` is **100% self-contained** (all styles, scripts, and data are inlined):

1. Go to your GitHub repository: **[`https://github.com/Omilia25/Omilia25.github.io`](https://github.com/Omilia25/Omilia25.github.io)**
2. Click **Add file** > **Upload files** (or click the link `uploading an existing file`).
3. Drag and drop just **`index.html`** (and optionally `README.md`).
4. Scroll to the bottom and click **Commit changes**.
5. Your updated portfolio will be live at:
   👉 **`https://omilia25.github.io`**
